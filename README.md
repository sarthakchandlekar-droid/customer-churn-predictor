# Customer Churn Predictor

A machine learning web app that predicts whether a telecom customer will churn.

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn, XGBoost
- Streamlit

## Project Structure
- data/raw — original dataset
- data/processed — cleaned and encoded data
- models — saved pkl files
- notebooks — EDA, preprocessing, training
- app — Streamlit web app
- src — reusable Python scripts

## How to Run
streamlit run app/app.py

## Dataset
Telco Customer Churn Dataset from Kaggle (7,043 customers, 21 features)
